# AI Screen Scanner
1. Відкрийте папку в Android Studio (Koala+), дочекайтесь Gradle Sync.
2. Run на телефоні (Android 8+; USB-налагодження) або Build > Build APK.
3. У застосунку вставте API-ключ Anthropic, натисніть «Запустити», видайте дозволи.
4. Відкрийте будь-який застосунок → плаваюча кнопка СКАНУВАТИ → відповідь у нижній панелі.
